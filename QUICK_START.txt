⚡ CRITICAL NOTICE:
   Microsoft Office Web Viewer requires documents to be publicly
   accessible from the internet.

❌ WON'T WORK:
   • localhost:8000 (your current development setup)
   • Private networks without internet access
   • Firewall-blocked servers

✅ WILL WORK:
   • Public production servers
   • Development with ngrok or similar tunneling
   • Cloud deployments (AWS, Azure, Heroku, etc.)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 1: Use ngrok (Recommended)

   Step 1: Install ngrok
      Download from: https://ngrok.com/
      Or: choco install ngrok (Windows)

   Step 2: Start ngrok
      ngrok http 8000

   Step 3: Update settings.py
      ALLOWED_HOSTS = ['localhost', '127.0.0.1', 'your-url.ngrok.io']

   Step 4: Access via ngrok URL
      Use the https://xxxxx.ngrok.io URL instead of localhost

   Step 5: Test!
      Upload a .docx file and click "View Online"

OPTION 2: Deploy to Production
   Deploy your app to a public server with a domain name.
   The Office Web Viewer will work automatically.

PROBLEM: "Document cannot be loaded"
   → Document URL not publicly accessible
   → Solution: Use ngrok or deploy to public server

PROBLEM: "Unsupported file type"
   → File type not supported (.pdf, .txt, etc.)
   → Solution: Only use .docx, .xlsx, .pptx files

PROBLEM: Slow loading
   → Large file or slow internet
   → Solution: Wait longer, or use Collabora for large files

PROBLEM: Button doesn't appear
   → File type check failing
   → Solution: Check document.file_type matches supported types
