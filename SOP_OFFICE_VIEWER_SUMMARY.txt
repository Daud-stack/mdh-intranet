🎯 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FROM SOP LIST PAGE:
   1. Navigate to /sop-manual/list/
   2. Look for SOPs with file attachments
   3. Click the green "👁" button (View Online)
   4. SOP opens in Office Web Viewer

FROM SOP DETAIL PAGE:
   1. View any SOP with a file attachment
   2. See the "Attachment" section
   3. Click "View Online" button
   4. SOP attachment opens in full-screen viewer

FEATURES IN VIEWER:
   • Full-screen document viewing
   • SOP metadata in header (title, version, category)
   • Download button for offline access
   • Return to SOP details button
   • Acknowledgment reminder in info banner

⚠️ IMPORTANT: Must use ngrok URL for this to work!

1. RESTART DJANGO (if not already done):
   - Terminal: Ctrl+C
   - Run: python manage.py runserver
   
2. ACCESS VIA NGROK:
   - URL: https://untyrantlike-buster-undesigningly.ngrok-free.dev
   - Click "Visit Site" on ngrok warning
   
3. CREATE OR UPDATE AN SOP WITH ATTACHMENT:
   a. Go to: /sop-manual/
   b. Create new SOP or edit existing (staff only)
   c. Upload a .docx file as attachment
   d. Save the SOP
   
4. TEST FROM SOP LIST:
   - Go to: /sop-manual/list/
   - Find the SOP with attachment
   - Click green "👁" button
   - Document should open in Office Web Viewer!
   
5. TEST FROM SOP DETAIL:
   - Click on any SOP with attachment
   - In attachment section, click "View Online"
   - Full-screen viewer opens
   
6. VERIFY FEATURES:
   □ Document loads and is readable
   □ Can scroll through document
   □ Read-only (no editing)
   □ Download button works
   □ Return button goes back to SOP details
   □ SOP metadata shown in header

→ Check: ngrok is still running
→ Check: File attachment exists and is not corrupted
→ Wait: Large files take time to load

→ Check: File type is supported
→ Try: Download the file instead
→ Check: ngrok URL is in ALLOWED_HOSTS
